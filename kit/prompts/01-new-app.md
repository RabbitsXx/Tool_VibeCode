# เริ่มแอป/เว็บใหม่

```
ฉันอยากสร้าง: [อธิบายไอเดียใน 1-3 ประโยค]
ผู้ใช้คือ: [ใคร / ใช้ตอนไหน]
สิ่งเดียวที่ต้องทำได้ดีที่สุด: [ผลลัพธ์หลัก]
ต้องมี: [3-7 ข้อ]
ไม่ต้องมี (ตอนนี้): [ข้อ]
ข้อจำกัด: [stack ที่ชอบ / ต้องรันบน Windows / งบ / เส้นตาย]

ทำตามนี้:
1. ตรวจเครื่องมือที่ติดตั้งอยู่จริง (node, python, git เวอร์ชันอะไร) แล้วเลือก stack ที่ง่ายที่สุดที่ตอบโจทย์ บอกเหตุผล 2 บรรทัด
2. ถามฉันไม่เกิน 3 ข้อ เฉพาะที่คำตอบเปลี่ยนผลลัพธ์จริง ส่วนที่เหลือเลือกค่าที่เหมาะสมเองแล้วจดใน "สมมติฐาน"
3. สร้างโครงโปรเจกต์ + AGENTS.md + docs/SPEC.md (เกณฑ์รับงานที่ตรวจได้) + docs/TASKS.md (ชิ้นเล็กที่รันได้ เรียงจากเสี่ยงสุดก่อน)
4. ทำชิ้นแรกให้รันได้จริงตั้งแต่ต้นจนจบ (walking skeleton) แล้วบอกวิธีรัน
5. git init และ commit แรก (ห้าม push)
สรุปท้ายสุด: สมมติฐานที่ตัดสินใจเอง, ชิ้นถัดไป, คำสั่งรัน
```

เคล็ด: ถ้ามีเว็บ/แอปที่ชอบสไตล์ ให้แปะลิงก์หรือบรรยาย 1 บรรทัดต่อท้าย จะช่วยมากกว่าบรรยายยาว ๆ
