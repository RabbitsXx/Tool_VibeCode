# AI วนแก้ซ้ำ ไม่ไปไหน

อาการ: error เดิมกลับมา, แก้แล้วพังที่อื่น, AI พูดว่า "น่าจะได้แล้ว" โดยไม่ได้รัน

```
หยุดแก้โค้ดก่อน เราวนอยู่ ทำตามนี้:
1. สรุปสั้น ๆ: เป้าหมายคืออะไร, ลองอะไรไปแล้วบ้าง, แต่ละอย่างได้ผลอะไรจริง (ไม่ใช่ที่คาดหวัง)
2. อ่าน error ล่าสุดทั้งหมดอีกครั้งตั้งแต่บรรทัดแรก และบอกว่ามันบอกอะไรตรง ๆ
3. ตั้งสมมติฐาน 2-3 ข้อ เรียงตามความเป็นไปได้ พร้อม "การทดลองเล็กที่สุด" ที่ยืนยันหรือล้มแต่ละข้อได้ (log, สคริปต์ทดสอบสั้น ๆ, คำสั่ง) รันการทดลองก่อน ห้ามแก้โค้ดจริงเพื่อ "ลองดู"
4. ถ้ายังไม่เจอสาเหตุ ให้บอกว่ายังไม่รู้อะไร และต้องการข้อมูลอะไรจากฉัน
5. เมื่อรู้สาเหตุจริงแล้วเท่านั้น จึงแก้ให้น้อยที่สุด แล้วรันซ้ำเพื่อพิสูจน์
```

ถ้ายังไม่ดีขึ้น: `/vibe-handoff` แล้วเปิด session ใหม่ + `/vibe-resume` (บทสนทนายาวทำให้ AI สับสนง่าย) หรือถอยไป `git stash` / `git checkout` กลับจุดที่ยังทำงานได้ แล้วทำใหม่ทีละขั้นเล็ก
