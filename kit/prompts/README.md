## หลักการเขียนพรอมต์ให้ได้งานในรอบเดียว
1. **บอกผลลัพธ์ ไม่ใช่วิธีทำ** — "ผู้ใช้กดปุ่มแล้วเห็นรายการเรียงตามวันที่" ดีกว่า "ใช้ sort ใน useEffect"
2. **บอกว่าเสร็จคืออะไร** — เขียนเป็นข้อที่ตรวจได้ ("เปิดบนมือถือแล้วไม่มีแถบเลื่อนแนวนอน")
3. **บอกขอบเขตและสิ่งห้าม** — "แก้เฉพาะหน้า login อย่าแตะ database"
4. **ชี้ไฟล์/ตัวอย่างที่ต้องทำตาม** — ให้ AI อ่านของจริงก่อนเขียน
5. **ให้ AI ตรวจงานตัวเอง** — "รันเทสต์และเปิดหน้าดูก่อนบอกว่าเสร็จ รายงานผลจริง"
6. **งานใหญ่ให้แตกเป็นชิ้นเล็กที่รันได้** — ทีละชิ้น ไม่ใช่ทั้งโปรเจกต์ในข้อความเดียว
