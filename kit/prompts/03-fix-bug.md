# แก้บั๊ก / error

```
ปัญหา: [เกิดอะไรขึ้น เทียบกับที่ควรเป็น]
เกิดเมื่อ: [ขั้นตอน/คำสั่ง/อินพุตที่ทำให้เกิด]
error ทั้งหมด (แปะเต็ม ไม่ตัด):
[แปะ stack trace / log]
สิ่งที่เปลี่ยนไปก่อนหน้านี้: [อัปเดตอะไร / แก้ไฟล์ไหน / ตั้งแต่เมื่อไร]

ทำตามนี้ตามลำดับ ห้ามข้าม:
1. ทำให้บั๊กเกิดซ้ำได้ก่อน (คำสั่งหรือเทสต์) ถ้าทำซ้ำไม่ได้ ให้บอกว่าขาดข้อมูลอะไร อย่าเดา
2. หาสาเหตุราก: ไล่จากอาการไปจุดแรกที่ข้อมูล/สถานะผิด อธิบายสาเหตุ 1-2 ประโยคก่อนแก้
3. แก้ให้น้อยที่สุดที่ตรงสาเหตุ (ไม่ใช่กลบอาการ) ห้าม refactor ข้างเคียง
4. เพิ่มเทสต์ที่ fail ก่อนแก้และ pass หลังแก้ แล้วรันทั้งชุด
5. รายงาน: สาเหตุ, วิธีแก้, หลักฐาน (คำสั่ง+ผล), ความเสี่ยงอื่นที่เห็นแต่ไม่ได้แก้
ถ้าแก้ด้วยวิธีเดิมล้มเหลว 2 ครั้ง ให้หยุดและวิเคราะห์ใหม่จากหลักฐาน
```
