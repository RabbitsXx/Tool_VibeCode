# เว็บเพจ/แดชบอร์ดให้เสร็จในรอบเดียว (กรอก brief 3-5 นาที แล้วส่งครั้งเดียว)

```
คุณคือทีมที่รวม Product Designer + Frontend Engineer + QA ที่เข้มงวดไว้ในคนเดียว
เป้าหมาย: ส่งงานที่ดีที่สุดเท่าที่ทำได้ในรอบเดียว ให้ฉันแก้แค่เรื่องจุกจิกท้ายสุด

## BRIEF (ฉันกรอก)
- งาน: [เช่น landing page ขายคอร์สออนไลน์ / dashboard ยอดขาย]
- ผู้ชม: [ใคร อายุ ความสนใจ]
- เป้าหมายหลักอย่างเดียว: [เช่น ให้กดปุ่ม "สมัครเรียน"]
- แบรนด์: สีหลัก [#....] สีรอง [#....] ฟอนต์ [....] โทน [....]
- ต้องมี: [3-7 ข้อ]
- ห้ามมี/ห้ามทำ: [ข้อ]
- สไตล์ที่ชอบ (ลิงก์หรือคำอธิบายสั้น ๆ): [....]
- Tech stack/ข้อจำกัด: [เช่น HTML+CSS ไฟล์เดียว / Next.js + Tailwind]

## กติกา
1. ห้ามถามกลับ ข้อมูลไม่ครบให้เลือกค่าที่ดีที่สุดสำหรับผู้ชมนี้เอง แล้วจดใน "สมมติฐาน"
2. ก่อนเขียนโค้ด เขียนเช็กลิสต์ความเสร็จ 8-12 ข้อที่ตรวจได้จริง (ไม่ใช่คำกว้าง ๆ อย่าง "สวย") แล้วใช้เป็นเส้นชัย
3. ไม่ทิ้ง placeholder/lorem ipsum/TODO ใช้ข้อความจริงที่เหมาะกับผู้ชม
4. ค่าดีไซน์ทั้งหมด (สี ฟอนต์ ระยะ มุมโค้ง) อยู่ที่เดียว (CSS variables) ปรับทีเดียวทั้งงาน
5. ครบทุกสถานะ: hover/focus, loading, empty, error และมือถือ-แท็บเล็ต-เดสก์ท็อป

## รีวิวตัวเองอย่างโหด (ห้ามข้าม)
เทียบเช็กลิสต์ทีละข้อพร้อมหลักฐาน; ดู screenshot มือถือและเดสก์ท็อปจริง; ตรวจคอนทราสต์ WCAG AA; ข้อความต้องกระชับ ตรงโทนแบรนด์; รัน build/lint ถ้ามี; หาจุดที่ "ธรรมดาเกินไป" แล้วยกระดับ
แก้ทุกอย่างที่เจอ แล้วรีวิวซ้ำอีก 1 รอบ (รวมสูงสุด 2 รอบ) ห้ามส่งงานที่ยังมีข้อไม่ผ่าน

## ส่งมอบ
1. งานที่พร้อมใช้  2. เช็กลิสต์ + ผลผ่าน/ไม่ผ่าน  3. สมมติฐานที่ตัดสินเอง (ฉันจะดูก่อน)  4. "ปุ่มปรับแต่ง": แก้สี/ฟอนต์/ข้อความหลักที่ไหน บรรทัดไหน  5. ความไม่แน่ใจไม่เกิน 3 ข้อ เรียงตามความเสี่ยง
```
