# ทำหน้าตา (UI) ให้ดี

```
ปรับ UI ของ: [หน้า/คอมโพเนนต์]
ผู้ใช้: [ใคร] ใช้บน [มือถือเป็นหลัก / เดสก์ท็อป / ทั้งสอง]
โทน/แบรนด์: สีหลัก [#....] ฟอนต์ [....] ความรู้สึก [เรียบ/พรีเมียม/เป็นกันเอง]
ห้าม: [เช่น เปลี่ยนโครงสร้างข้อมูล, เพิ่มไลบรารี]

ขั้นตอน:
1. อ่านสไตล์/ค่าดีไซน์ที่มีอยู่และใช้ซ้ำ ถ้าไม่มี ให้รวมสี ฟอนต์ ระยะห่าง มุมโค้งไว้ที่เดียว (CSS variables)
2. เปิดดูของจริงที่กว้าง ~375 / ~768 / ~1280px (ถ้ามีเครื่องมือเบราว์เซอร์) อย่าตัดสินจากโค้ดอย่างเดียว
3. แก้ตามลำดับ: ลำดับความสำคัญของสายตา (ปุ่มหลักต้องชัด) → ระยะห่างสม่ำเสมอ → ครบทุกสถานะ (hover, focus, loading, ว่าง, error, สำเร็จ) → responsive (ไม่มีแถบเลื่อนแนวนอนบนมือถือ, ปุ่มกดได้ใหญ่พอ 44px) → การเข้าถึง (คอนทราสต์ AA, โฟกัสด้วยคีย์บอร์ด, label, alt)
4. เปลี่ยนข้อความ placeholder เป็นข้อความจริงที่เหมาะกับผู้ใช้ กระชับ ไม่ฟังเหมือน AI เขียน
5. สรุป: แก้อะไร ตรวจที่ความกว้างไหนแล้ว ยังเหลืออะไร
```
